# 豆屿 · 拼豆管理

30 秒产品实录，展示图纸管理、MARD 221 色库存、用量检查和选色专注。

[![豆屿产品 Demo](demo-cover.jpg)](bead-studio-demo-30s.mp4)

[观看 / 下载 30 秒视频](bead-studio-demo-30s.mp4) · [中文字幕](demo-subtitles.zh-CN.srt)

视频规格：1920 × 1080，30 fps，H.264 MP4，时长 30 秒，字幕已嵌入画面，无音轨。

演示流程：

- 查看收藏图纸与库存概览
- 查看 MARD 色号库存
- 选择待拼图纸，自动对照所需、库存与缺少颗数
- 开始制作，进入拼中状态
- 进入专注模式：选中色号保留原色，其余豆子变为黑白
- 切换白色、蓝色和黑色，定位当前色号

演示使用独立本地数据，不修改线上库存。
